A Portico Account identifies a person. A Portico Server holds a media library and decides what that person can see and do on that server.

## One account, several servers

One account can belong to more than one server. Access on one server doesn't give access to any other server.

## Server owner

The owner controls the server: its libraries, people, remote access, maintenance and administrative settings. Keep owner access limited. When you can, use a normal viewer account for everyday watching.

## Administrator

An owner can give administrative permissions to another person they trust. Give them only the access they need for the work they do. Don't use administrative access as a way around library permissions.

## Viewer

A viewer can browse and play the libraries assigned to their account. Each profile keeps its own progress, saved items, history, ratings and preferences. Use a separate profile for each person's viewing choices.
