The Server Console is the server administration area under **Settings → Server**. Its controls are grouped into pages. Owners see the full set; administrators see the sections their role allows.

## Check current activity

Open **Dashboard** for **Now playing**, **Alerts**, **Health**, **Background activity**, and **Viewing statistics**. **Now playing** shows active streams and playback decisions. **Background activity** shows server work. **Health** reports database state, uptime and storage, with processor, memory, graphics, network and disk measurements where available.

## Find logs and records

Open **Troubleshooting** for **Logs**, **Server records**, server capabilities, client reports and **Support export**. Logs can be filtered by level and category and followed live. Server records separate server, client and audit events.

Use **Support export** to prepare a downloadable diagnostic file with a selected time window and record types. See [Read logs and diagnostics](/docs/administration/logs-and-diagnostics/).

## Check version and connection details

Open **General** for the installed version, update information and restart controls. Include the installed version and platform when reporting a problem after an update.

Open **Remote access** for outside reachability, local addresses, router mappings and certificate details. See [Read the connection status](/docs/remote/read-connection-status/).
